You can now capture just one element of a page instead of the whole screen. Set a Screenshot Target — a CSS selector — under Advanced Web Page Options, and Blitapp will crop the screenshot to that element. How it works Open a capture’s Advanced Web Page Options and fill in the new Screenshot Target field with a CSS selector, for example: #pricing — capture the element with id pricing .hero —...
