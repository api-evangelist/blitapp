With Blitapp, you can inject JavaScript into any page to log in, click on elements, etc. To expand the range of possible interactions and simplify them, we have added automation steps . On this blog, we will post several examples using automation steps, including: Complex login to a website Log in to a site and take screenshots of multiple pages Take screenshots of a carousel with all the elements Select multiple elements on a page Automation steps The automation steps describe the list of commands that the browser must execute.
